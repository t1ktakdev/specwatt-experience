# V4.1.1 · исправления независимого аудита

База: PR №3, commit `183fe52a226ef7870aeccb08c8772cccf24579e3`. Отдельная ветка `codex/experience-v411-review-fixes`; исходный V4.1 и основной SpecWATT не редактируются. Figma изменяется в существующем файле, Planner остаётся узлом `75:2002`.

Условия приёмки:

1. Кнопка первого расписания остаётся внутри карточки и совпадает с React по координатам; сохранены снимки до/после.
2. При 1.0 Home показывает устройства и действия, без отдельного пустого верхнего toolbar; плотность остальных экранов соответствует назначению и Figma.
3. В Android нет повторяющихся label/detail и избыточных основных CTA для обычной навигации.
4. Android system bars тёмные, контент учитывает реальные insets; edge-to-edge не отключается.
5. При 1.3/1.5 системный шрифт сохраняется; компоновка адаптируется, навигация доступна, поля и кнопки не обрезаны.
6. Все 12 маршрутов и три шага просмотрены в React, Figma и Android с конкретными замечаниями и исправлениями.
7. CH3/7 Вт, отказ 8.4 Вт, согласия, offline и локальная демонстрация сохраняются; регрессии, CI и новый APK проверены.
8. Проверены реальные цели прототипа; отсутствие playback не выдаётся за проверенное воспроизведение.

Подтверждённые дефекты: Figma `75:2139` имеет ширину 100 при дочерней кнопке 305, что даёт x=-102.5. Native toolbar отделён от экранных заголовков, формируя избыточную высоту. Tile содержит лишний ряд иконки/канала под самим предметом. `NativeAutopilot` передаёт одинаковые label/detail. Android system bar светлый; для API 35+ проверяются contrast enforcement и фон под edge-to-edge.

Результат и доказательства: [REVIEW.md](REVIEW.md), [сравнение изображений](review.html). В ходе проверки также исправлены незакреплённая навигация Figma Prototype, пропущенные переходы и регулировка Lighting при вертикальной прокрутке. На Android выполнены 13 сквозных сценариев; жест ползунка проверен отдельно при трёх fontScale. Системные значки эмулятора API 35 остаются отдельным ограничением, не помеченным как исправленное. Полная визуальная приёмка остаётся за пользователем.
